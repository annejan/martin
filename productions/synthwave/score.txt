# An ORIGINAL martin background loop — moody demoscene synthwave in A minor, 124 BPM.
# Hand-composed using the jantje lessons: clean sustained lead = the singing, clean bass,
# four-on-floor in the drops, a sparkly arp riff in the lead's gaps, per-bar chords, build→drop arc.
bpm 124

# i–VI–III–VII in Am — the classic synthwave turnaround
chords Am F C G

# intro (pad+arp) → build (add bass+kick) → drop (full + lead) → break → climax (lead up) → outro
section intro    4
section build    8  8
section drop     8  8
section break    4
section climax   8  8
section outro    4
